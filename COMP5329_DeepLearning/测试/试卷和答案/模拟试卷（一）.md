### 1. 正则化（选 incorrect）

Which of the following statements about reducing overfitting in deep networks is **incorrect**?

- [ ] A. Dropout can be viewed as implicitly training an ensemble of subnetworks; at test time the full network is used, with the training-time scaling chosen so the expected activation is preserved.
- [ ] B. L2 regularization corresponds to a Gaussian prior on the weights and shrinks them toward zero, but it does not usually drive individual weights to be exactly zero.
- [ ] C. L1 regularization tends to yield sparse solutions because its diamond-shaped constraint region tends to touch the loss contours at the coordinate axes.

### 2. 矩阵乘法效率（basic calculation）

Given $A\in\mathbb R^{m\times n}$, $B\in\mathbb R^{n\times p}$, $C\in\mathbb R^{p\times q}$ with $m<n<p<q$, which computation order is **most efficient**?

- [ ] A. $(AB)C$
- [ ] B. $A(BC)$
- [ ] C. Both orders cost the same, since matrix multiplication is associative.
- [ ] D. $A(BC)$ in general, unless $B$ is sparse, in which case $(AB)C$.

> [!success]- Answer
>
> **📌 考 matrix-chain 计算量。** ⚠️ 笔记未专写，真题/老师卷都考。
>
> **大白话：** 结合律只保证结果相同、不保证代价相同。代入 $m<n<p<q$（如 1,2,3,4）算一下就知道 $(AB)C$ 更省。
>
> **得分点：**
> - **选 A $(AB)C$**
> - $(AB)C$：$mnp+mpq=mp(n+q)$；$A(BC)$：$npq+mnq=nq(m+p)$。
> - 取 $m{=}1,n{=}2,p{=}3,q{=}4$：$(AB)C=6+12=18$，$A(BC)=24+8=32$ → $(AB)C$ 更省。
> - **C 错**：关联律不改变结果但改变计算量；**D 错**：把更优顺序写反。

### 5. 注意力机制（选 correct）

Which statement about the $\sqrt{d_k}$ scaling in scaled dot-product attention is **correct**?

- [ ] A. Dividing the scores by $\sqrt{d_k}$ keeps the dot-product variance roughly independent of $d_k$, preventing the softmax from entering a low-gradient saturated regime.
- [ ] B. The $\sqrt{d_k}$ factor is needed to make the attention matrix symmetric, so that queries and keys become interchangeable.
- [ ] C. Removing the $\sqrt{d_k}$ scaling does not affect gradients, because softmax is invariant to the scale of its input.
- [ ] D. The $\sqrt{d_k}$ factor reduces the number of parameters in each attention head in proportion to the key dimension.

>

>
> **大白话：** $q\cdot k$ 的方差 $\approx d_k$，不缩放 → 分数过大 → softmax 饱和、梯度趋零。除以 $\sqrt{d_k}$ 把方差拉回 ≈1。

### Q1 — Backpropagation（推导 + 计算）

A three-layer network (input $x$ → hidden $y=f(\text{net}_y)$ → output $z$) is trained with MSE loss $J=\tfrac12(t-z)^2$.

- **(a)** Write the output-layer sensitivity $\delta_k$ and hidden-layer sensitivity $\delta_j$, and state what $\delta$ means physically. **(4 Marks)**
- **(b)** Tiny net: input $x=1$, one sigmoid hidden unit with weight $w=0.5$, linear output with weight $v=2$, target $t=1$. Compute $\partial J/\partial w$ numerically. **(5 Marks)**
- **(c)** Using the $\delta$ recursion, explain why a deep sigmoid network suffers vanishing gradients in its bottom layers. **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W2 backprop & chain rule。** ✅「第一组」Backprop + Sigmoid。
>
> **大白话：** backprop = 责任追溯；每过一层乘一次 $f'$。Sigmoid $f'\le0.25$，连乘后底层梯度指数衰减。
>
> **得分点：**
>
> **(a)** $\delta_k=(t_k-z_k)f'(\text{net}_k)$；$\delta_j=f'(\text{net}_j)\sum_k\delta_k w_{kj}$；更新 $\Delta w=\eta\,\delta\cdot(\text{输入})$。$\delta$ = loss 对该单元**净输入**的敏感度（该单元对最终误差的“责任”）。
>
> **(b)** $\text{net}_y=0.5$，$y=\sigma(0.5)\approx0.622$，$z=vy=1.245$，$z-t=0.245$。
> $$\frac{\partial J}{\partial w}=(z-t)\,v\,\underbrace{y(1-y)}_{\sigma'}\,x=0.245\times2\times(0.622\times0.378)\times1\approx\mathbf{0.115}$$
>
> **(c)** 底层梯度 $\propto\prod_l f'(\text{net}^{(l)})W$；Sigmoid $f'=\sigma(1-\sigma)\le0.25$，多层连乘指数趋零 → 底层几乎不更新（动机：改 ReLU / 残差）。

### Q4 — Attention & Transformer（coding + 论述）

- **(a)** Implement `scaled_dot_product_attention(Q, K, V, mask=None)` from scratch, then explain (variance argument) why we divide by $\sqrt{d_k}$. **(6 Marks)**
- **(b)** A single Transformer layer with only Multi-Head Attention trains unstably. Which components are missing, and what does each contribute? **(4 Marks)**
- **(c)** State the key difference in **attention masking** between BERT and GPT, and why each suits its task. **(4 Marks)**

> [!success]- Answer
>
> **📌 考 W8 attention / Transformer / BERT vs GPT。** ✅「第三组」Part 4–5。
>
> **大白话：** attention = `QKᵀ/√d_k → mask → softmax → ×V`；完整层还要 FFN + 残差 + LN + 位置编码；BERT 双向、GPT 因果。
>
> **得分点：**
>
> **(a)**
> ```python
> import math, torch
> def scaled_dot_product_attention(Q, K, V, mask=None):
>     d_k = Q.shape[-1]
>     scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)
>     if mask is not None:
>         scores = scores.masked_fill(mask == 0, float("-inf"))
>     return torch.softmax(scores, dim=-1) @ V
> ```
> 缩放理由：内积方差 $\approx d_k$，不缩放 → softmax 饱和、梯度趋零；$/\sqrt{d_k}$ 拉回方差 ≈1。
>
> **(b)** 缺 **FFN**（逐 token 非线性）、**残差 + LayerNorm**（稳定/梯度直路）、**位置编码**（注顺序，否则置换不变）。层 = `LN(x+MHA(x))` → `LN(x+FFN(x))`。
>
> **(c)** BERT 无 causal mask、双向 → MLM、理解任务；GPT 因果 mask（只看 $\le i$）→ next-token、生成。BERT 不能自回归生成（双向会看到未来 token）。

### Q7 — Adversarial Examples（novel-context 压轴 · 论述）

> *本题为「研究扩展型」novel-context 题：adversarial robustness 不是核心讲义专章，题干已给足背景；要求你用**已学的梯度、决策边界、正则化/数据增广、泛化**等核心知识归纳推理作答——这是期末压轴的典型形式。*

**背景：** A well-trained image classifier labels a panda image as "panda" with 57.7% confidence. Adding a tiny, human-imperceptible perturbation to the pixels causes the model to label it "gibbon" with 99.3% confidence. The perturbation is computed using the model's own gradients with respect to the input.

- **(a)** Using your knowledge of how a model's outputs depend on its inputs (gradients) and the geometry of decision boundaries, explain why an imperceptible perturbation can flip the prediction and even raise the (wrong) confidence. **(5 Marks)**
- **(b)** Propose **two** defenses, each drawing on a principle you have studied (e.g. data augmentation, regularization, smoothing/ensembling), and discuss one trade-off of each. **(6 Marks)**
- **(c)** Is adversarial robustness the same as high standard test accuracy? Relate your answer to the notions of generalization and distribution shift. **(4 Marks)**

> [!success]- Answer
>
> **📌 考 novel-context（对抗鲁棒性）。** ❌ 笔记**无专章** → 用「第一组」梯度/决策边界/正则/增广 + 泛化概念推理。
>
> **大白话：** 高维决策边界很“脆”，沿输入梯度方向走一小步就能越界；因为模型局部近似线性，许多小扰动在高维上叠加成大效应，越过边界后错误类的 softmax 反而更高。防御=训练时见过对抗样本（≈增广）或推理时平滑/集成。鲁棒 ≠ 干净测试准确率高。
>
> **得分点：**
>
> **(a)** 模型对输入的局部敏感度由 $\nabla_x L$ 决定；沿 $\mathrm{sign}(\nabla_x L)$ 方向加微小扰动（FGSM 思想）能高效增大 loss。高维下决策边界近似线性，许多维度上的小扰动**线性叠加**成显著 logit 变化 → 越过边界进入错误类区域，错误类 softmax 概率可更高。人眼不可察是因为 $\|\delta\|_\infty$ 很小。
>
> **(b)**（任选两，含 trade-off）
> - **Adversarial training**（训练时把对抗样本当增广喂进去）：直接提升鲁棒性；代价：训练成本高、对未见攻击泛化有限、可能略降干净准确率。
> - **Input smoothing / randomized ensembling**（多次加噪前向取平均/投票）：平滑预测、提供一定 certified robustness；代价：推理变慢。
> - **（也可答）正则化 / Lipschitz 约束 / distillation 平滑边界**：降低对输入的敏感度；代价：约束过强会 underfit。
>
> **(c)** **不等同**。标准测试准确率衡量在与训练**同分布**数据上的泛化；adversarial robustness 衡量在**最坏情况扰动（分布外）**下的稳定性。模型可干净准确率很高却极不鲁棒——存在 robustness–accuracy trade-off。本质是对 **distribution shift / worst-case** 的泛化，而非平均情形泛化。

### Q8 — Mamba / State Space Models（novel-context 压轴 · 论述）

> *本题仿老师样卷 Q4：Mamba/SSM 作为前沿扩展，题干给足结构描述；每小问锚定一个核心概念（位置处理 / 长程依赖 / 记忆瓶颈），要求结合 RNN/LSTM 与 Transformer 的已学知识作整合分析。*

**背景：** Mamba is a State Space Model (SSM). Like an RNN it keeps a **fixed-size** hidden state updated step by step, $s_t = A\,s_{t-1} + B\,x_t$ with learnable $A,B$, but the recurrence is **linear** with a data-dependent gate, so the whole sequence of states can be computed in **parallel** via a fast scan. Unlike a Transformer (which stores and revisits **all** previous tokens, so per-step cost and memory grow with sequence length), Mamba carries information forward only through its single fixed-size state.

- **(a)** A standard Transformer cannot tell the order of its input tokens and must add positional encoding. Which property of self-attention causes this? Why can Mamba's way of processing a sequence work **without** positional encoding? **(4 Marks)**
- **(b)** When an LSTM processes a very long sequence, distant information is hard to retain. What is the root cause? Through what different mechanism does a Transformer avoid it? On this point, how is Mamba **similar to and different from** the LSTM and the Transformer? **(5 Marks)**
- **(c)** A Transformer can access all past tokens losslessly, but at generation time this has a cost. What bottleneck does it face and what is its root cause? What design do Mamba/RNNs use to avoid it, and what new limitation does that design itself introduce? **(6 Marks)**

> [!success]- Answer
>
> **📌 考 novel-context（W8 SSM/Mamba ↔ RNN/LSTM/Transformer）。** ✅「第三组」Part 7 + Part 1/2/4 推理。
>
> **大白话：** self-attention 是置换不变的→必须加位置编码；Mamba 是按时间步递推，顺序天然编码进状态。LSTM 长程难是连乘梯度消失；Transformer 用直接注意力绕开；Mamba 像 RNN 走单一状态、又像 Transformer 能并行。Transformer 生成时 KV cache 随长度增长是瓶颈；固定状态 $O(1)$ 内存解决，但代价是“压成一个固定向量”可能丢信息。
>
> **得分点：**
>
> **(a)** self-attention **permutation-invariant**（打乱 token 输出集合不变）→ 无内建顺序 → 需 positional encoding。Mamba 按**时间步递推**处理，状态更新顺序本身编码了 token 顺序，顺序信息天然进入 $s_t$，故无需显式位置编码。
>
> **(b)** LSTM 根因：长序列上梯度沿时间连乘（即便门控仍是连乘因子），远处信息/梯度衰减。Transformer 机制：**任意两位置直接 self-attention**，距离为 1 跳，信息几乎不衰减。Mamba：**像 LSTM/RNN** 用单一递推状态前传（非两两交互）；**像 Transformer** 可并行训练（线性递推 + scan）且数据相关门控选择性保留信息，缓解了普通 RNN 的衰减。
>
> **(c)** Transformer 瓶颈：自回归生成需 **KV cache**，内存/每步成本随序列长度 $O(N)$ 线性增长（根因：要保留并重访所有历史 token 的 K/V）。Mamba/RNN：只维护**固定大小状态**，推理内存/每步成本 $O(1)$（与长度无关）。新限制：所有历史被压进一个固定容量状态 → **信息瓶颈**，可能丢失需要精确回溯的细节（不如注意力的“无损访问”）。
