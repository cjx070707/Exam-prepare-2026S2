### 1. 正则化（选 incorrect）

Which of the following statements about reducing overfitting in deep networks is **incorrect**?

- [ ] A. Dropout can be viewed as implicitly training an ensemble of subnetworks; at test time the full network is used, with the training-time scaling chosen so the expected activation is preserved.
- [ ] B. L2 regularization corresponds to a Gaussian prior on the weights and shrinks them toward zero, but it does not usually drive individual weights to be exactly zero.
- [ ] C. L1 regularization tends to yield sparse solutions because its diamond-shaped constraint region tends to touch the loss contours at the coordinate axes.
- [ ] D. Batch Normalization reduces overfitting mainly by decreasing the number of trainable parameters, which lowers the model's effective capacity.

> [!success]- Answer
>
> **📌 考 W3 正则化机制辨析。** ✅「第一组」Part 5。
>
> **大白话：** A/B/C 都是正确机制描述。D 把 BN 的正则来源说成“减少参数→降容量”，恰恰说反——BN **增加** $\gamma,\beta$ 参数，其正则效果来自 **batch 噪声**。

> **得分点：**

### 2. 矩阵乘法效率（basic calculation）

Given $A\in\mathbb R^{m\times n}$, $B\in\mathbb R^{n\times p}$, $C\in\mathbb R^{p\times q}$ with $m<n<p<q$, which computation order is **most efficient**?

- [ ] A. $(AB)C$
- [ ] B. $A(BC)$
- [ ] C. Both orders cost the same, since matrix multiplication is associative.
- [ ] D. $A(BC)$ in general, unless $B$ is sparse, in which case $(AB)C$.

> [!success]- Answer
>
> **📌 考 matrix-chain 计算量。** ⚠️ 笔记未专写，真题/老师卷都考。
>
> **大白话：** 结合律只保证结果相同、不保证代价相同。代入 $m<n<p<q$（如 1,2,3,4）算一下就知道 $(AB)C$ 更省。
>
> **得分点：**
> - **选 A $(AB)C$**
> - $(AB)C$：$mnp+mpq=mp(n+q)$；$A(BC)$：$npq+mnq=nq(m+p)$。
> - 取 $m{=}1,n{=}2,p{=}3,q{=}4$：$(AB)C=6+12=18$，$A(BC)=24+8=32$ → $(AB)C$ 更省。
> - **C 错**：关联律不改变结果但改变计算量；**D 错**：把更优顺序写反。

### 3. 序列模型（选 incorrect）

Which of the following statements about RNNs and LSTMs is **incorrect**?

- [ ] A. In a vanilla RNN, backpropagation through time repeatedly multiplies by $\tanh'(\cdot)\,W_{hh}$, which can shrink gradients exponentially and hinder long-range learning.
- [ ] B. The gradient along an LSTM's cell-state path passes through a factor approximately equal to the forget gate, which is learnable and can be pushed close to 1.
- [ ] C. An LSTM mitigates vanishing gradients purely because its cell-state update is additive, which eliminates all multiplicative factors along the temporal path.
- [ ] D. An LSTM has roughly four times as many recurrent weight matrices as a same-width vanilla RNN, owing to its three gates plus the candidate cell state.

> [!success]- Answer
>
> **📌 考 W7 RNN/LSTM 梯度。** ✅「第三组」Part 1–2（含纠误点）。
>
> **大白话：** A/B/D 都对。C 是经典误区——LSTM 不是“靠加法消除了所有乘法”，它仍是乘法，只是把固定小乘数换成**可学习的** $f_t$。

### 5. 注意力机制（选 correct）

Which statement about the $\sqrt{d_k}$ scaling in scaled dot-product attention is **correct**?

- [ ] A. Dividing the scores by $\sqrt{d_k}$ keeps the dot-product variance roughly independent of $d_k$, preventing the softmax from entering a low-gradient saturated regime.
- [ ] B. The $\sqrt{d_k}$ factor is needed to make the attention matrix symmetric, so that queries and keys become interchangeable.
- [ ] C. Removing the $\sqrt{d_k}$ scaling does not affect gradients, because softmax is invariant to the scale of its input.
- [ ] D. The $\sqrt{d_k}$ factor reduces the number of parameters in each attention head in proportion to the key dimension.

> [!success]- Answer
>
> **📌 考 W8 attention 缩放（方差视角）。** ✅「第三组」Scaled Dot-Product Attention。
>
> **大白话：** $q\cdot k$ 的方差 $\approx d_k$，不缩放 → 分数过大 → softmax 饱和、梯度趋零。除以 $\sqrt{d_k}$ 把方差拉回 ≈1。
>
> **得分点：**
> - **选 A（correct）**
> - **B 错**：与对称性无关。**C 错**：softmax **不是** scale-invariant，缩放直接影响梯度。**D 错**：缩放与参数量无关。

### Q1 — 优化器选择（反直觉诊断）

A team trains a CNN. With **SGD + momentum** the loss decreases slowly. After switching to **Adam**, training loss drops much faster, but the final **test accuracy is noticeably lower** than the best SGD run.

- **(a)** Explain, in terms of how Adam adapts per-parameter step sizes, why it converges faster on training loss. **(3 Marks)**
- **(b)** Give a plausible reason why the Adam model generalizes worse, despite the lower training loss. **(4 Marks)**
- **(c)** Propose a concrete training strategy that keeps Adam's fast early progress but recovers SGD-like generalization. **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W3 优化器对比 / 泛化。** ✅「第一组」Adam / SGD。
>
> **大白话：** Adam 给每个参数自适应步长 → 早期收敛快；但它常落到更“尖锐”的极小值，泛化不如 SGD 的平坦解。常见做法：前期 Adam、后期切 SGD，或用 AdamW + lr 衰减。
>
> **得分点：**
>
> **(a)** Adam 用一阶矩定方向、二阶矩 $\sqrt{\hat v_t}$ 对每个参数自适应缩放步长 → 梯度量级差异大的参数也能稳定快速下降 → 训练 loss 降得快。
>
> **(b)** 自适应步长容易收敛到 **sharp minima**（对参数扰动敏感），泛化差；且 Adam 把 L2 与自适应缩放耦合，等效正则被削弱（→ 过拟合训练集）。低训练 loss ≠ 低测试误差。
>
> **(c)** 任选其一：① **先 Adam 后切 SGD+momentum**（SWATS 思路）做最后精修；② 换 **AdamW**（解耦 weight decay）+ **lr 衰减 / warm restart**；③ 调小 lr、加正则。要点是“保留早期速度 + 末期找平坦解”。

### Q2 — Normalization 调试（场景诊断）

You train an object detector but, due to memory, each GPU holds only **batch size = 2**. Training loss decreases fine, yet validation accuracy is unstable and clearly worse than training.

- **(a)** Why is **BatchNorm** a likely culprit specifically under this tiny-batch setting? **(3 Marks)**
- **(b)** Which normalization would you switch to, and why does it behave better here? **(3 Marks)**
- **(c)** If you must keep BatchNorm, name one practical way to reduce the problem. **(2 Marks)**

> [!success]- Answer
>
> **📌 考 W3 BN 局限 + 四种 Norm 对比。** ✅「第一组」Batch Normalization / 四种 Normalization。
>
> **大白话：** BN 依赖 batch 统计，batch=2 时均值/方差噪声极大，且训练用 batch 统计、推理用 running 统计，两者 mismatch → 验证不稳。换成与 batch 无关的 GroupNorm/LayerNorm 就稳。
>
> **得分点：**
>
> **(a)** BN 的 $\mu_B,\sigma_B^2$ 在 batch 内估计；batch=2 时估计**噪声极大、不可靠**，且 train（batch 统计）↔ test（running 统计）行为不一致 → 验证不稳定且偏差大。

> **(b)** 换 **GroupNorm（或 LayerNorm）**：在**单个样本**的通道（组）维归一化，**与 batch size 无关**，小 batch 下统计稳定、train/test 行为一致。

> **(c)** 任选其一：**SyncBN**（跨多卡同步统计，增大有效 batch）/ 冻结预训练 BN 的 running stats / 增大每卡 batch（减分辨率或梯度检查点换显存）。注意：单纯**梯度累积不**修复 BN（统计仍按小 batch 算）。

### Q3 — 按需求设计 CNN（情境里藏计算）

You design a classifier for $224\times224$ inputs. Requirement: each neuron in the **4th convolutional layer** must “see” a region of **at least $32\times32$** of the input (receptive field), while keeping parameters small.

- **(a)** Propose a concrete conv stack (kernel / stride / pooling / #layers) and **compute the receptive field at the 4th conv layer** to verify it meets the requirement. **(5 Marks)**
- **(b)** Why use stacked $3\times3$ convs instead of one large kernel to grow the receptive field? **(3 Marks)**
- **(c)** If you used dilated convolutions to reach the same receptive field, what do you save and what is the downside? **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W4 感受野 / 尺寸 / VGG / dilated。** ✅「第二组」Part 1。
>
> **大白话：** 感受野递推 $r_l=r_{l-1}+(k_l-1)\prod_{i<l}s_i$。光堆 3×3 (s=1) 涨得慢，插 pooling（s=2）让“跳距”翻倍，感受野迅速变大。
>
> **得分点：**
>
> **(a)** 一种设计：`[Conv3×3(s1) → MaxPool2×2(s2)] × 3 → Conv3×3(s1)`。逐层递推（$j$ 为 jump）：
> - Conv3：$r=1+(3-1)\cdot1=3,\ j=1$；Pool：$r=3+(2-1)\cdot1=4,\ j=2$
> - Conv3：$r=4+(3-1)\cdot2=8,\ j=2$；Pool：$r=8+(2-1)\cdot2=10,\ j=4$
> - Conv3：$r=10+(3-1)\cdot4=18,\ j=4$；Pool：$r=18+(2-1)\cdot4=22,\ j=8$
> - **第 4 个 Conv3**：$r=22+(3-1)\cdot8=\mathbf{38}\ge32$ ✅
>
> **(b)** 两个 3×3 = 一个 5×5 感受野，参数 $18<25$，且多一次 ReLU → 更省参 + 更强非线性（VGG 思路）。
>
> **(c)** Dilated conv 在**不下采样、不加参数**的情况下扩大感受野（保留分辨率，利于分割）；代价：采样有“**网格洞**(gridding)”、跳采样可能漏掉局部细节。

### Q4 — 部署约束下的架构决策（工程决策）

You have a large, accurate **ViT** that is too slow to run **real-time video** classification on a phone.

- **(a)** From the complexity of self-attention, explain why the ViT is slow (especially on video). **(3 Marks)**
- **(b)** Propose **two** concrete redesign directions (you may draw on CNN inductive bias, efficient/windowed attention, distillation, MoE, token reduction), each with one trade-off. **(6 Marks)**
- **(c)** Why is “just halving the number of layers” often a poor way to speed it up? **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W8 attention 复杂度 + ViT/CNN + 效率工具。** ✅「第三组」ViT/Transformer +「第四组」MoE。
>
> **大白话：** self-attention 是 $O(T^2 d)$，video 的 patch/token 数 $T$ 很大 → 平方爆炸。提速要么换有 inductive bias 的 CNN、要么用窗口注意力把 $O(T^2)$ 降线性、要么蒸馏成小模型。
>
> **得分点：**
>
> **(a)** self-attention 复杂度 $O(T^2\cdot d)$，$T$=patch（视频还要乘帧数）→ token 多时平方级计算/内存，实时跑不动。
>
> **(b)**（任选两，各一个代价）
> - **换/混入 CNN backbone**：locality+权重共享，$O(HW\,k^2C)$ 更省、小数据更好；代价：全局建模弱。
> - **窗口/线性注意力（如 Swin）**：把 $O(T^2)$ 降到近线性；代价：跨窗口长程交互受限、实现复杂。
> - **知识蒸馏**到小 student；代价：需教师 + 额外训练，精度略降。
> - **MoE**：大容量但每 token 只激活 top-k，推理省算力；代价：显存大、路由复杂。
> - **token/patch 合并**减少 $T$；代价：可能丢细粒度信息。
>
> **(c)** 砍一半层**均匀降低容量**、伤精度，且每层仍是 $O(T^2)$——没动“token 数平方”这个真正瓶颈；针对性降 $T$ 或换注意力更有效。

### Q5 — 改 bug：注意力实现（coding 调试）

A teammate's attention returns **NaN** on long sequences and seems to **attend to padded positions**. Their code:

```python
def attention(Q, K, V, mask=None):
    scores = Q @ K.transpose(-2, -1)        # (B, T, T)
    if mask is not None:                    # mask: 1 = keep, 0 = pad
        scores = scores * mask
    weights = torch.softmax(scores, dim=-1)
    return weights @ V
```

- **(a)** Identify the **two** bugs and write the corrected function. **(6 Marks)**
- **(b)** Explain why each bug caused its symptom (NaN vs. leaking into padded positions). **(4 Marks)**

> [!success]- Answer
>
> **📌 考 W8 scaled dot-product attention 实现细节。** ✅「第三组」+ 速查表 Week7。
>
> **大白话：** 两个 bug：① 没除 $\sqrt{d_k}$ → 长序列/大维度时分数过大、$e^{\text{score}}$ 溢出成 inf → softmax 出 NaN；② 用 `scores*mask` 把 pad 位置变 0，但 0 在 softmax 里仍有权重（且真实分数可能为负）→ 还是会 attend 到 pad。应填 $-\infty$。
>
> **得分点：**
>
> **(a)**
> ```python
> import math
> def attention(Q, K, V, mask=None):
>     d_k = Q.shape[-1]
>     scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)   # 修 bug1：缩放
>     if mask is not None:
>         scores = scores.masked_fill(mask == 0, float("-inf"))  # 修 bug2：填 -inf
>     weights = torch.softmax(scores, dim=-1)
>     return weights @ V
> ```
>
> **(b)**
> - **Bug1（NaN）**：缺 $/\sqrt{d_k}$，$d_k$ 或序列大时分数巨大，$\exp$ 溢出 → inf/inf = **NaN**。
> - **Bug2（泄漏到 pad）**：`*mask` 只把分数置 0，softmax 后仍分到非零权重；正确做法是把 pad 位填 $-\infty$，$\exp(-\infty)=0$ 才真正屏蔽。

### Q6 — GAN 病象诊断（反直觉诊断）

Your GAN trains with a **low, stable loss**, yet almost every generated image looks **nearly identical**.

### Q7 — Knowledge Distillation（novel-context 压轴 · 论述）

> *研究扩展型 novel-context 题：知识蒸馏不是讲义专章，背景已给；要求用你学过的 **softmax / 温度 / 集成 / 泛化** 等核心知识推理作答。*

**背景：** To compress a large accurate "teacher" network into a small "student", you train the student to match not only the hard labels but also the teacher's **soft probabilities**, produced by a softmax with a **temperature** $T$: $\;p_i = \dfrac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$.

- **(a)** Why do the teacher's soft labels carry **more information** than one-hot hard labels? Reason via the softmax outputs ("dark knowledge"). **(4 Marks)**
- **(b)** What is the effect of making the temperature $T$ larger vs. smaller? **(3 Marks)**
- **(c)** Relate distillation to (i) the ensemble interpretation of Dropout and (ii) defensive distillation against adversarial attacks. **(4 Marks)**

> [!success]- Answer
>
> **📌 考 novel-context（知识蒸馏）。** ❌ 笔记无专章 → 用「第一组」softmax/Dropout 集成 + 泛化推理。
>
> **大白话：** 软标签里藏着“类间相似度”——teacher 说“这张图 90% 猫、9% 狗、1% 车”，比硬标签“猫”信息多得多（dark knowledge）。温度调大让分布更平滑、暴露更多类间关系。
>
> **得分点：**
>
> **(a)** 硬标签只给 top-1；软标签的非目标类概率编码了**类间相似结构**（“猫更像狗、不像车”），即 dark knowledge → student 学到更丰富的决策几何 → 用更少数据/参数逼近 teacher。
>
> **(b)** $T$ **大** → 分布更平滑（熵高），放大非目标类的相对信息，但区分度下降；$T$ **小**（→1）→ 接近 one-hot，退化为硬标签。蒸馏常用较大 $T$ 训练、推理时 $T=1$。
>
> **(c)** (i) **Dropout 集成**：训练像隐式集成多个子网；蒸馏可把一个**大集成/teacher 的知识压进单个 student**（集成 → 单模型迁移）。(ii) **Defensive distillation**：用软标签训练**平滑决策边界**，降低对输入的梯度敏感度 → 提升对 adversarial 扰动的鲁棒性。

### Q8 — Mamba / State Space Models（novel-context 压轴 · 论述）

> *仿老师样卷 Q4：Mamba/SSM 作为前沿扩展，背景已给；每小问锚定一个核心概念（位置处理 / 长程依赖 / 记忆瓶颈），要求整合 RNN/LSTM 与 Transformer 的已学知识。*

**背景：** Mamba is a State Space Model. Like an RNN it keeps a **fixed-size** hidden state updated step by step, $s_t = A\,s_{t-1} + B\,x_t$ with learnable $A,B$, but the recurrence is **linear** with a data-dependent gate, so the whole sequence of states can be computed in **parallel** via a fast scan. Unlike a Transformer (which stores and revisits **all** previous tokens, so per-step cost and memory grow with sequence length), Mamba carries information forward only through its single fixed-size state.

- **(a)** A standard Transformer cannot tell token order and needs positional encoding. Which property of self-attention causes this? Why can Mamba work **without** positional encoding? **(4 Marks)**
- **(b)** When an LSTM processes a very long sequence, distant information is hard to retain — root cause? Through what different mechanism does a Transformer avoid it? How is Mamba **similar to and different from** both? **(5 Marks)**
- **(c)** A Transformer accesses all past tokens losslessly, but at generation time this costs. What bottleneck and root cause? What design do Mamba/RNNs use to avoid it, and what new limitation does that design bring? **(6 Marks)**

> **📌 考 novel-context（W8 SSM/Mamba ↔ RNN/LSTM/Transformer）。** ✅「第三组」Part 7 + Part 1/2/4 推理。
>
> **大白话：** attention 置换不变→必须加位置编码；Mamba 按时间步递推，顺序天然编码进状态。LSTM 长程难=连乘梯度衰减；Transformer 用直接注意力绕开；Mamba 像 RNN 走单一状态、又像 Transformer 能并行。生成时 Transformer 的 KV cache 随长度增长是瓶颈，固定状态 $O(1)$ 内存解决但会丢信息。
>
> **得分点：**
>
> **(a)** self-attention **permutation-invariant**（打乱 token 输出集合不变）→ 无内建顺序 → 需 positional encoding。Mamba 按**时间步递推**，更新顺序本身把 token 顺序编码进 $s_t$，故无需显式位置编码。
>
> **(b)** LSTM 根因：长序列梯度沿时间**连乘**衰减，远处信息难保留。Transformer 机制：任意两位置**直接 self-attention**（距离 1 跳），信息几乎不衰减。Mamba：**像 RNN/LSTM** 用单一递推状态前传（非两两交互）；**像 Transformer** 可并行训练（线性递推 + scan），且数据相关门控选择性保留信息，缓解普通 RNN 衰减。
>
> **(c)** Transformer 瓶颈：自回归生成需 **KV cache**，内存/每步成本随序列长度 $O(N)$ 线性增长（根因：保留并重访所有历史 K/V）。Mamba/RNN：只维护**固定大小状态**，推理 $O(1)$（与长度无关）。新限制：历史被压进固定容量状态 → **信息瓶颈**，可能丢失需精确回溯的细节（不如注意力“无损访问”）。
