### 1. ReLU Dead Neuron

During training of an image classifier, you notice a group of ReLU neurons output exactly 0 for **every** input and their weights stop changing. Which explanation best fits?

- [ ] A. Their pre-activation became persistently negative, so the ReLU gradient is 0 and the weights receive no update signal.
- [ ] B. ReLU saturates for large positive inputs, flattening the gradient at the upper end.
- [ ] C. The neurons reached the global optimum, so the optimizer correctly froze them.
- [ ] D. Batch Normalization forced their activations to zero mean, zeroing the output.

> [!success]- Answer
>
> **📌 考 W2 ReLU / Dead ReLU。** ✅「第一组」ReLU。
>
> **大白话：** ReLU 负区间输出恒 0、梯度恒 0。一旦某神经元的净输入被推到长期为负（初始化差或学习率过大），它就永远收不到梯度、参数不再更新——“死”了。
>
> **得分点：**
> - **选 A** — 净输入持续 $<0$ → 梯度 0 → 权重不更新（Dead ReLU）。
> - **B 错**：ReLU 正区间**不饱和**（梯度恒为 1）；饱和是 Sigmoid/Tanh 的问题。
> - **C 错**：输出恒 0 是病态，不是收敛到最优。
> - **D 错**：BN 有 $\gamma,\beta$ 可恢复分布，不会强制输出 0。

### 4. GAN 中“完美判别器”的后果

While training a GAN, the discriminator quickly becomes near-perfect ($D\approx1$ on real, $\approx0$ on fake). The generator's gradient then vanishes. Which statement best explains this?

- [ ] A. When the real and generated supports barely overlap, the objective behaves like a constant JS divergence, so the generator receives near-zero gradient.
- [ ] B. The generator has reached mode collapse, which always coincides with a perfect discriminator.
- [ ] C. The discriminator's BatchNorm removed the gradient signal.
- [ ] D. A perfect discriminator means training has converged successfully.

> [!success]- Answer
>
> **📌 考 W12 GAN 训练不稳定 / JS 散度。** ✅「第四组」GAN。
>
> **大白话：** 高维下 $p_r$ 与 $p_g$ 支撑集几乎不重叠，存在完美判别器，此时目标 ≈ 常数 $\log 2$（JS 饱和），梯度趋零——判别器太强反而“杀死”生成器。
>
> **得分点：**
> - **选 A** — support 几乎不重叠 → $\mathcal L(G,D^*)=2\,\mathrm{JS}(p_r\|p_g)-2\log2$ 近似常数 → 梯度消失。
> - **B 错**：mode collapse 与梯度消失是**两个独立问题**，不必同时发生。
> - **C 错**：与 BN 无关。
> - **D 错**：完美判别器是病态，不是收敛。

### Q1 — Backpropagation（推导 + 计算）

A three-layer network (input $x$ → hidden $y=f(\text{net}_y)$ → output $z$) is trained with MSE loss $J=\tfrac12(t-z)^2$.

- **(a)** Write the output-layer sensitivity $\delta_k$ and the hidden-layer sensitivity $\delta_j$, and state the physical meaning of $\delta$. **(4 Marks)**
- **(b)** Consider a tiny net: one input $x=1$, one sigmoid hidden unit with weight $w=0.5$, a linear output with weight $v=2$, target $t=1$. Compute $\partial J/\partial w$ numerically. **(5 Marks)**
- **(c)** Using the $\delta$ recursion, explain why a deep network using sigmoid activations suffers vanishing gradients in the bottom layers. **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W2 backprop & chain rule。** ✅「第一组」Backprop 推导 + Sigmoid。
>
> **大白话：** backprop 是“责任追溯”——输出层误差按权重逐层往回分配，每过一个隐藏层都要乘一次 $f'$。Sigmoid 的 $f'\le0.25$，连乘后底层梯度指数衰减。
>
> **得分点：**
>
> **(a)** 输出层 $\delta_k=(t_k-z_k)\,f'(\text{net}_k)$；隐藏层 $\delta_j=f'(\text{net}_j)\sum_k\delta_k w_{kj}$；权重更新 $\Delta w=\eta\,\delta\cdot(\text{输入})$。$\delta$ = loss 对该单元**净输入**的敏感度，即“该单元对最终误差的责任”。
>
> **(b)** 前向：$\text{net}_y=w x=0.5$，$y=\sigma(0.5)\approx0.622$，$z=v y=1.245$，$z-t=0.245$。
> $$\frac{\partial J}{\partial w}=(z-t)\cdot v\cdot \underbrace{y(1-y)}_{\sigma'}\cdot x=0.245\times2\times(0.622\times0.378)\times1\approx \mathbf{0.115}$$
> （写出链式四项即给分；数值 $\approx0.115$。）
>
> **(c)** 底层梯度 $\propto\prod_l f'(\text{net}^{(l)})\cdot W$。Sigmoid 的 $f'=\sigma(1-\sigma)\le0.25$，多层连乘 → 指数级趋零 → 底层几乎不更新（vanishing gradient）。这正是改用 ReLU / 残差连接的动机。

A model reaches 99% training accuracy but only 70% validation accuracy.

- **(b)** Explain how Dropout improves generalization, covering **both** the ensemble view and the co-adaptation view, and state how inverted dropout behaves at train vs test time. **(5 Marks)**
- **(c)** It is often said BatchNorm "reduces the need for Dropout". Give one reason why. **(2 Marks)**

> - **Dropout**：训练随机置零神经元，减少 co-adaptation。

### Q3 — CNN 基础（计算 + 概念）

- **(a)** An input $32\times32$ goes through Conv ($K{=}3,P{=}1,S{=}1$) → MaxPool ($2\times2,S{=}2$) → Conv ($K{=}3,P{=}1,S{=}1$). Give the spatial size after each layer. **(4 Marks)**

- **(c)** VGG replaces one $5\times5$ conv with two stacked $3\times3$ convs. Show they have the same receptive field, and compare parameter counts (per input-output channel pair). **(4 Marks)**

> [!success]- Answer
>
> **📌 考 W4 conv 计算 + weight sharing + VGG。** ✅「第二组」Part 1 + VGGNet。
>
> **大白话：** conv 逐层套公式；同一 filter 滑过全图 → 平移等变；pooling 取局部最大 → 平移不变；两个 3×3 = 一个 5×5 的视野但参数更少、非线性更多。

### Q4 — Graph Convolutional Networks（推导 + 对比）

You build a GNN for node classification on a social network.

- **(a)** The naive graph convolution $\sigma(AH^{l}W^{l})$ has two problems. Identify them and write Kipf's final propagation rule that fixes both. **(6 Marks)**
- **(b)** Why use **symmetric** normalization $\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$ rather than row normalization $\tilde D^{-1}\tilde A$? **(3 Marks)**
- **(c)** Give one situation where representing image data as a graph (GCN) is more appropriate than a regular grid (CNN). **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W5 Spatial GCN（Kipf）。** ✅「第二组」Part 4。
>
> **大白话：** naive $AH$ 既漏了自己、又没归一化（大度数节点主导）。Kipf 加自环 $\tilde A=A+I$ 再做对称归一化，两个独立问题分别解决。
>
> **得分点：**
>
> **(a)**
> - 问题 1：$A$ 不含自环 → 聚合时丢失节点自身特征 → 加自环 $\tilde A=A+I$。
> - 问题 2：$A$ 未归一化 → 高度数节点特征尺度爆炸 → 归一化。
> - Kipf 公式：$H^{(l+1)}=\sigma\!\big(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}H^{(l)}W^{(l)}\big)$，$\tilde A=A+I$，$\tilde D$ 为 $\tilde A$ 的度矩阵。

>
> **(c)** 像素关系本身是图结构时——如 **scene graph / superpixel graph / 点云 k-NN 图**：节点度可变、无固定排序，GCN 的 permutation equivariance 比 CNN 的网格假设更合适。

### Q5 — LSTM（推导）

A vanilla RNN fails to learn dependencies across a 100-step sequence.

- **(a)** Write the three gate equations ($f_t,i_t,o_t$), the candidate $\tilde c_t$, the cell-state update $c_t$, and the hidden output $h_t$. **(5 Marks)**
- **(b)** Using $\partial c_t/\partial c_{t-1}$, explain why LSTM mitigates vanishing gradients better than a vanilla RNN. Correct the common misconception that "it's purely because of the additive structure". **(5 Marks)**
- **(c)** What happens to long-term memory if the forget gate $f_t$ is learned to be near 0? **(2 Marks)**

> [!success]- Answer
>
> **📌 考 W7 LSTM 门机制 + 梯度。** ✅「第三组」Part 2。
>
> **大白话：** RNN 梯度要连乘 $\tanh'\cdot W_{hh}$（$\le1$）→ 消失。LSTM 的 cell state 梯度只乘 $f_t$，而 $f_t$ **可学习**（可训到≈1）→ 梯度近乎无损传递。不是“因为加法”，而是“把固定小乘数换成可学习乘数”。
>
> **得分点：**
>
> **(a)** $f_t=\sigma(W_{fh}h_{t-1}+W_{fx}x_t)$，$i_t=\sigma(\cdot)$，$o_t=\sigma(\cdot)$，$\tilde c_t=\tanh(W_{hh}h_{t-1}+W_{hx}x_t)$；$\;c_t=c_{t-1}\otimes f_t+\tilde c_t\otimes i_t$；$\;h_t=o_t\otimes\tanh(c_t)$。
>
> **(b)** 沿 cell state 路径 $\dfrac{\partial c_t}{\partial c_{t-1}}\approx f_t$，长程梯度 $\propto\prod_t f_t$。$f_t=\sigma(\cdot)$ **可学习**，能训练到 $\approx1$ → 梯度长期保留。对比 RNN 的 $\prod_t\tanh'(\cdot)W_{hh}$ 是**固定且 $\le1$** 的因子，连乘指数衰减。**纠误**：LSTM 仍是乘法（不是纯加法消除连乘），关键是那个乘数**可学习**。
>
> **(c)** $f_t\approx0$ → $c_t\approx i_t\otimes\tilde c_t$，旧细胞状态被完全重置 → **丧失长期记忆**。

### Q6 — Attention & Transformer（coding + 论述）

- **(a)** Implement `scaled_dot_product_attention(Q, K, V, mask=None)` from scratch (returning the attention output, supporting an optional mask). Then explain, from a **variance** argument, why we divide by $\sqrt{d_k}$. **(6 Marks)**
- **(b)** A handwritten single-layer Transformer with only Multi-Head Attention trains unstably. Which components are missing, and what does each contribute? **(4 Marks)**
- **(c)** State the key difference in **attention masking** between BERT and GPT, and why each suits its task. **(4 Marks)**

> [!success]- Answer
>
> **📌 考 W8 attention / Transformer / BERT vs GPT。** ✅「第三组」Part 4–5。
>
> **大白话：** attention = `QKᵀ/√d_k → mask → softmax → ×V`。不缩放则内积方差 $\approx d_k$，softmax 进饱和区、梯度近 0。完整 Transformer 层还要 FFN + 残差 + LN + 位置编码。BERT 双向、GPT 因果。
>
> **得分点：**
>
> **(a)**
> ```python
> import math, torch
> def scaled_dot_product_attention(Q, K, V, mask=None):
>     d_k = Q.shape[-1]
>     scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)
>     if mask is not None:
>         scores = scores.masked_fill(mask == 0, float("-inf"))
>     weights = torch.softmax(scores, dim=-1)
>     return weights @ V
> ```
> 缩放理由：$q,k$ 各 $d_k$ 维，内积方差 $\approx d_k$；不除 $\sqrt{d_k}$ 时分数过大 → softmax 接近 one-hot（饱和）→ 梯度趋零。除以 $\sqrt{d_k}$ 把方差拉回 $\approx1$。
>
> **(b)** 缺：**FFN**（逐 token 非线性变换）、**残差连接 + LayerNorm**（稳定训练、梯度直路）、**位置编码**（注入顺序，否则置换不变）。完整层 = `LN(x+MHA(x))` → `LN(x+FFN(x))`。
>
> **(c)** **BERT**：无 causal mask，**双向**，每个位置看全序列 → MLM 预训练，适合**理解**（分类/QA）。**GPT**：**因果 mask**（位置 $i$ 只看 $\le i$）→ next-token 预测，适合**自回归生成**。BERT 不能直接自回归生成，因为双向会“看到未来 token”。

### Q7 — ResNet / PyTorch（coding，参考真题 Q7 + Tutorial）

A very deep plain CNN shows **higher training error** than a shallower one (degradation problem). You use residual blocks instead.

- **(a)** Implement a `ResidualBlock(nn.Module)`: two $3\times3$ convs (each + BatchNorm), ReLU, and a skip connection that uses a $1\times1$ conv when channel count or stride changes. **(6 Marks)**

- **(c)** Sketch a training loop for 100 epochs that validates every 5th epoch (printing accuracy), applies early stopping, and saves the model every 10th epoch. **(5 Marks)**

> [!success]- Answer
>
> **📌 代码来源**：Tutorial `Week5_CNN.ipynb`（Part B `BasicBlock` + DataLoader/train loop）；真题 Q7 同款。理论见「第二组」ResNet（退化问题 + skip connection）。
>
> **大白话：** 两路 3×3 conv+BN，输出 `F(x)+shortcut(x)` 再 ReLU；维度不匹配时 shortcut 走 1×1 conv 对齐。数据用 `Compose`，`ToTensor()` 已缩到 [0,1]。训练循环在标准 loop 上加“每 5 验证 / 早停 / 每 10 存盘”。
>
> **(a)**
> ```python
> import torch.nn as nn
> import torch.nn.functional as F
>
> class ResidualBlock(nn.Module):
>     def __init__(self, in_c, out_c, stride=1):
>         super().__init__()
>         self.conv1 = nn.Conv2d(in_c, out_c, 3, stride, padding=1, bias=False)
>         self.bn1 = nn.BatchNorm2d(out_c)
>         self.conv2 = nn.Conv2d(out_c, out_c, 3, 1, padding=1, bias=False)
>         self.bn2 = nn.BatchNorm2d(out_c)
>         self.shortcut = (nn.Sequential(
>             nn.Conv2d(in_c, out_c, 1, stride, bias=False), nn.BatchNorm2d(out_c))
>             if stride != 1 or in_c != out_c else nn.Identity())
>
>     def forward(self, x):
>         out = F.relu(self.bn1(self.conv1(x)))
>         out = self.bn2(self.conv2(out))
>         return F.relu(out + self.shortcut(x))
> ```
> **关键词**：$F(x)+x$、skip connection、1×1 conv 对齐 channel/stride。
>
> **(b)**
> ```python
> from torchvision import transforms
> import torch, torchvision
>
> transform = transforms.Compose([
>     transforms.Resize((224, 224)),
>     transforms.RandomHorizontalFlip(),
>     transforms.ToTensor(),            # RGB ∈ [0,1]
> ])
> loader = torch.utils.data.DataLoader(dataset, batch_size=32, shuffle=True)
> ```
> 要 [0,1] 就只用 `ToTensor()`，不要再加 `Normalize`。
>
> **(c)**
> ```python
> best_acc, no_improve = 0.0, 0
> for epoch in range(1, 101):
>     model.train()
>     for x, y in train_loader:
>         optimizer.zero_grad()
>         loss = criterion(model(x), y)
>         loss.backward(); optimizer.step()
>
>     if epoch % 5 == 0:                       # 每 5 验证
>         acc = evaluate(model, val_loader)
>         print(f"epoch {epoch} val acc {acc:.4f}")
>         if acc > best_acc:
>             best_acc, no_improve = acc, 0
>         else:
>             no_improve += 1
>         if no_improve >= patience:           # 早停
>             break
>     if epoch % 10 == 0:                      # 每 10 存盘
>         torch.save(model.state_dict(), "inception.pth")
> ```
> **关键词**：`model.train()/eval()`、`zero_grad → backward → step`、`% 5` 验证、early stopping、`torch.save(state_dict)`。

### Q8 — Generative Models（论述 + 推导）

- **(a)** Write the GAN minimax objective, derive the optimal discriminator $D^*(x)$ for a fixed $G$, and explain what the objective reduces to and why a near-perfect $D$ kills the generator's gradient. **(5 Marks)**
- **(b)** Write the VAE ELBO (two terms, state each one's role), and explain why the reparameterization trick is necessary. **(4 Marks)**
- **(c)** Using the generative trilemma, compare **GAN / VAE / Diffusion (DDPM)** on sample quality, sampling speed, and mode coverage. **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W12 GAN / VAE / DDPM 对比。** ✅「第四组」Week 12。
>
> **大白话：** GAN 对抗博弈，最优判别器代入后等价最小化 JS 散度；分布不重叠时 JS 常数、梯度消失。VAE 最大化 ELBO（重建 + KL），重参数化把随机性外包给 ε 让梯度可回传。三类生成模型质量/速度/多样性难以兼得。
>
> **得分点：**
>
> **(a)** 目标：$\min_G\max_D\;\mathbb E_{x\sim p_r}[\log D(x)]+\mathbb E_{z\sim p_z}[\log(1-D(G(z)))]$。
> 固定 $G$ 求导得最优判别器 $D^*(x)=\dfrac{p_r(x)}{p_r(x)+p_g(x)}$。
> 代入后 $\mathcal L(G,D^*)=2\,\mathrm{JS}(p_r\|p_g)-2\log2$ → GAN 在最小化 **JS 散度**。
> 高维下 $p_r,p_g$ 支撑集几乎不重叠 → JS $=\log2$（常数）→ 梯度趋零 → 完美 $D$ “杀死”生成器。
>
> **(b)** $\log p_\theta(x)\ge\underbrace{\mathbb E_{q_\phi}[\log p_\theta(x|z)]}_{\text{重建项}}-\underbrace{D_\text{KL}(q_\phi(z|x)\|p(z))}_{\text{KL 正则项}}$。重建项让 decoder 能重建 $x$；KL 项让后验贴近先验 $\mathcal N(0,I)$，隐空间连续可采样。**重参数化** $z=\mu+\sigma\odot\epsilon,\;\epsilon\sim\mathcal N(0,I)$：采样本身不可微，把随机性移到无参数的 $\epsilon$ 上，梯度才能流回 $\mu,\sigma$。
>
> **(c)**
> | | 样本质量 | 采样速度 | Mode coverage |
> |---|---|---|---|
> | **GAN** | 高（清晰） | 快（1 步） | 差（mode collapse） |
> | **VAE** | 中（偏模糊） | 快 | 好 |
> | **DDPM** | 高 | 慢（1000+ 步） | 好 |
>
> → 三者不能同时占满；Flow Matching / Rectified Flow 主攻“diffusion 慢”。
