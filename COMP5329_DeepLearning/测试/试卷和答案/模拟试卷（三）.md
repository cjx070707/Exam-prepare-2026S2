### Q1 — VAE 训练诊断（场景诊断）

You train a VAE on face images. The reconstructions are sharp and accurate, but when you sample $z\sim\mathcal N(0,I)$ and decode, most generated faces are distorted garbage.

- **(a)** Which term of the ELBO is likely being under-weighted, and what does this cause in the latent space? **(4 Marks)**
- **(b)** Write out the full ELBO objective, labeling the reconstruction term and the KL term. **(3 Marks)**
- **(c)** Explain why the reparameterization trick is needed for training, in terms of gradient flow. **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W12 VAE / ELBO / 重参数化。** ✅「第四组」VAE。
>
> **大白话：** 重建好但采样垃圾 = KL 被压太低了。隐空间没被约束到高斯先验附近 → 到处是空洞 → 从 $\mathcal N(0,I)$ 采到的 z 大部分落在没见过的区域 → 解码出垃圾。
>
> **得分点：**
>
> **(a)** **KL 正则项**被 under-weighted → 隐空间不紧凑、不连续（encoder 把不同数据编码到隐空间中互不重叠的"孤岛"）→ 先验 $\mathcal N(0,I)$ 采样点大部分落在空洞区域 → decoder 没在那些区域训练过 → 生成垃圾。
>
> **(b)** $\mathcal L = \underbrace{\mathbb E_{z\sim q_\phi(z|x)}[\log p_\theta(x|z)]}_{\text{重建项（越大越好）}} - \underbrace{D_\text{KL}(q_\phi(z|x)\|p(z))}_{\text{正则项（越小越好）}}$，最大化 ELBO = 最大化重建质量 + 约束后验靠近先验。
>
> **(c)** 训练需要对 $z$ 求梯度，但 $z\sim q_\phi(z|x)$ 是**采样操作（不可微）**。重参数化把 $z=\mu_\phi(x)+\sigma_\phi(x)\odot\epsilon$（$\epsilon\sim\mathcal N(0,I)$），随机性转移到与参数无关的 $\epsilon$ 上 → $z$ 对 $\mu,\sigma$ 可微 → 梯度能流回 encoder 参数。

### Q2 — DDPM 前向与训练（公式 + 计算）

A diffusion model uses $T=1000$ timesteps with noise schedule $\beta_t$.

- **(a)** Write the formula for sampling $x_t$ directly from $x_0$ in one step (using $\bar\alpha_t$). **(3 Marks)**
- **(b)** Write the simplified training objective (predict-noise formulation). **(3 Marks)**
- **(c)** At inference the model starts from pure noise and iterates $T$ steps. Why is this slow compared to GAN, and name one technique to reduce the number of steps. **(4 Marks)**

> [!success]- Answer
>
> **📌 考 W12 DDPM 前向 / 训练目标 / 推理慢。** ✅「第四组」DDPM + Trilemma。
>
> **大白话：** 前向加噪可以一步到位：$x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$。训练目标就是"预测加进去的噪声"的 MSE。推理要走 1000 步去噪，每步都过一次网络，而 GAN 一次前向就出图。
>
> **得分点：**
>
> **(a)** $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$，其中 $\bar\alpha_t=\prod_{s=1}^t(1-\beta_s)$，$\epsilon\sim\mathcal N(0,I)$。
>
> **(b)** $\mathcal L = \mathbb E_{x_0,\epsilon,t}\big[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\big]$（网络预测噪声 $\epsilon_\theta$，与真实噪声 $\epsilon$ 的 MSE）。
>
> **(c)** GAN 只需 **1 次** generator 前向传播；DDPM 需 **T 次**（每步一次完整网络前向）→ 慢 ~1000×。减少步数的技术（任选一）：**DDIM**（确定性采样、跳步）/ **蒸馏到少步模型** / **在低维 latent 空间做扩散（Latent Diffusion）** / **Flow Matching（直线 ODE，步数更少）**。

### Q3 — DQN 场景调试（场景诊断）

You implement a DQN for a simple grid-world. Training diverges: the Q-values grow unboundedly and the agent's behavior oscillates wildly.

- **(a)** Identify the two well-known causes of DQN training instability, and for each, explain why it leads to divergence. **(5 Marks)**
- **(b)** State the corresponding trick (one for each cause) and explain how it stabilizes training. **(5 Marks)**
- **(c)** Write the DQN loss function (one-step Bellman MSE). **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W10 DQN / Experience Replay / Target Network。** ✅「第四组」DQN。
>
> **大白话：** DQN 不稳定的两个根因：① 连续 transition 高度相关，违反 i.i.d. → 网络 overfit 到局部轨迹、梯度偏 → Q 值漂移；② target 用的是自己（边学边变），追移动靶 → 正反馈循环爆炸。
>
> **得分点：**
>
> **(a)**
> - **Correlations between consecutive samples**：连续 $(s_t,a_t,r_{t+1},s_{t+1})$ 高度相关，违反 SGD 的 i.i.d. 假设 → 梯度有偏 → 训练不稳定。
> - **Non-stationary targets**：Bellman target $r+\gamma\max_{a'}Q_w(s',a')$ 使用同一个不断更新的网络 → target 每步都变 → "追自己的尾巴"、正反馈循环 → Q 值爆炸。
>
> **(b)**
> - **Experience Replay**：把 transition 存入 buffer、随机均匀采样 → 打破时序相关性、近似 i.i.d.。
> - **Target Network**：用参数延迟同步的副本 $Q_{w^-}$ 计算 target → target 固定 N 步不变 → 稳定训练方向。
>
> **(c)** $\mathcal L = \big(r + \gamma\max_{a'}Q_{w^-}(s',a') - Q_w(s,a)\big)^2$（$w^-$ 为 target network 参数，$w$ 为在线网络参数）。

### Q4 — LoRA 微调预算（工程决策 + 计算）

You need to fine-tune a 7B-parameter language model on a domain-specific task. Full fine-tuning requires storing gradients and optimizer states for all 7B parameters, exceeding your single-GPU memory.

- **(a)** Explain the core idea of LoRA: what is frozen, what is trained, and write the weight formula. **(4 Marks)**
- **(b)** If the original weight matrix is $W_0\in\mathbb R^{4096\times 4096}$ and rank $r=8$, compute the number of trainable parameters from LoRA vs. the original matrix. **(3 Marks)**
- **(c)** Why must $B$ be initialized to zero? What would go wrong if both $A$ and $B$ were randomly initialized? **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W9 LoRA。** ✅「第四组」LoRA。
>
> **大白话：** 冻结原始权重 $W_0$，只训练一个低秩"补丁" $\Delta W=BA$。参数从千万级降到万级。B=0 保证初始时 $\Delta W=0$，从预训练的精确状态开始；否则一上来就加随机噪声、破坏预训练权重。
>
> **得分点：**
>
> **(a)** **冻结** $W_0$，**训练** 低秩分解 $B\in\mathbb R^{d\times r}$ 和 $A\in\mathbb R^{r\times k}$。推理时 $W = W_0 + BA$。核心假设：微调时权重更新是低秩的（$r\ll\min(d,k)$）。
>
> **(b)** 原始：$4096\times4096 = \mathbf{16{,}777{,}216}$。LoRA：$B$ 有 $4096\times8 = 32{,}768$，$A$ 有 $8\times4096 = 32{,}768$，合计 $\mathbf{65{,}536}$。压缩比 $\approx 256\times$。
>
> **(c)** $B=0$ → 初始 $\Delta W = BA = 0$ → 从**预训练模型的精确状态**出发微调。若 $B$ 也随机初始化 → 训练开始时 $\Delta W\neq 0$，相当于在预训练权重上叠加了随机噪声 → **破坏已学到的表示**，训练起点差、可能不收敛。

### Q5 — 写码：VAE 重参数化（coding）

Implement the `reparameterize` function for a VAE. The encoder outputs `mu` and `log_var` (both shape `(B, d)`). Return a sampled `z` of the same shape that supports backpropagation through `mu` and `log_var`.

- **(a)** Write `reparameterize(mu, log_var)`. **(5 Marks)**
- **(b)** Explain why directly sampling $z\sim\mathcal N(\mu,\sigma^2I)$ would block gradient flow, and how your implementation fixes it. **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W12 VAE 重参数化 coding。** ✅「第四组」VAE + 速查表。
>
> **大白话：** 采样是不可微操作，梯度没法穿过随机节点。把 $z = \mu + \sigma\cdot\epsilon$ 里的随机性"外包"给 $\epsilon$（无参数），$z$ 对 $\mu,\sigma$ 就可微了。
>
> **得分点：**
>
> **(a)**
> ```python
> import torch
>
> def reparameterize(mu, log_var):
>     std = torch.exp(0.5 * log_var)        # σ = exp(0.5 * log σ²)
>     eps = torch.randn_like(std)            # ε ~ N(0, I)
>     return mu + std * eps                  # z = μ + σ⊙ε
> ```
>
> **(b)** 直接从 $\mathcal N(\mu,\sigma^2I)$ 采样 $z$ 是**随机操作（不可微）**，梯度无法穿过 → encoder 参数收不到梯度。重参数化把 $z=\mu+\sigma\odot\epsilon$，$\epsilon$ 是外部噪声（与 $\mu,\sigma$ 无关），$z$ 对 $\mu,\sigma$ 变成确定性函数 → **梯度可以流回** encoder。

### Q6 — Policy Gradient vs Q-Learning（对比决策）

A robotics team must choose between Q-Learning and Policy Gradient for training a robot arm with a **continuous** action space (joint angles).

- **(a)** Why is standard (tabular/DQN-style) Q-Learning problematic for continuous action spaces? **(3 Marks)**
- **(b)** How does Policy Gradient naturally handle continuous actions? Write the core gradient expression. **(4 Marks)**
- **(c)** Policy Gradient can have high variance. Name the standard technique to reduce it (using the advantage function), and explain intuitively why it helps. **(4 Marks)**

> [!success]- Answer
>
> **📌 考 W10 Q-Learning vs Policy Gradient。** ✅「第四组」Q-Learning + Policy Gradient。
>
> **大白话：** Q-Learning 要对所有动作算 Q 值再取 max，连续空间动作无限多、没法枚举。Policy Gradient 直接参数化策略（输出连续分布的参数），天然适合。方差大的问题用 advantage = "这个动作比平均好多少"做基线来降。
>
> **得分点：**
>
> **(a)** Q-Learning 的核心操作是 $\max_{a'}Q(s',a')$——需要遍历所有动作。连续空间动作无穷多，**无法枚举取 max**（DQN 输出所有动作的 Q 值也不适用，因为输出维度无限）。
>
> **(b)** Policy Gradient 直接参数化策略 $\pi_\theta(a|s)$（连续空间可输出高斯分布的 $\mu,\sigma$），从中采样动作。梯度：$\nabla_\theta J = \mathbb E[\nabla_\theta\log\pi_\theta(a|s)\cdot Q^\pi(s,a)]$——好动作增大概率，坏动作减小概率。
>
> **(c)** **Advantage baseline**：将 $Q$ 替换为 $A(s,a) = Q(s,a) - V(s)$（"这个动作比该状态的平均水平好多少"）。减去 baseline 不改变梯度期望（因为 $\mathbb E[\nabla\log\pi\cdot V]=0$），但**大幅降低方差**——只对"比平均好/差多少"给信号，而不是对绝对回报值。

### Q7 — CLIP 零样本推理（novel-context 压轴 · 论述）

> *研究扩展型 novel-context 题：CLIP 的零样本分类机制不是讲义专章重点，背景已给；要求用你学过的 **对比学习 / softmax 温度 / embedding 空间** 等核心知识推理作答。*

**背景：** CLIP jointly trains an image encoder and a text encoder using contrastive learning on 400M image-text pairs. At test time, **zero-shot classification** works without any task-specific training: given an image and $K$ candidate class labels, each label is wrapped into a prompt (e.g., "a photo of a {label}"), encoded by the text encoder, and the image is matched to the class whose text embedding has the highest cosine similarity with the image embedding.

- **(a)** CLIP's training loss is a symmetric variant of InfoNCE applied to image-text pairs. Explain how positives and negatives are defined in a batch of $N$ pairs, and what the loss encourages in the shared embedding space. **(5 Marks)**
- **(b)** At zero-shot inference, no training is done on the target classes. Explain why this works, in terms of what the shared embedding space has learned during pretraining. **(4 Marks)**
- **(c)** The cosine similarities are divided by a learned temperature $\tau$ before softmax. Drawing on what you know about temperature in contrastive learning, explain what happens if $\tau$ is too small or too large, and why learning $\tau$ is preferable to fixing it. **(5 Marks)**

> [!success]- Answer
>
> **📌 考 novel-context（CLIP 零样本 ↔ 对比学习 / 温度）。** ✅「第四组」CLIP + InfoNCE + 温度。
>
> **大白话：** CLIP 让图和文在同一个空间里"靠近配对的、远离不配对的"。因为预训练覆盖了海量自然语言描述，推理时新类别只要能用文字描述，就能在这个空间里找到对应的位置——不需要额外训练。温度控制 softmax 的尖锐程度。
>
> **得分点：**
>
> **(a)** 一个 batch 有 $N$ 对 (image, text)。**正样本**：第 $i$ 张图与第 $i$ 条文本（配对）。**负样本**：第 $i$ 张图与第 $j\neq i$ 条文本（batch 内所有不配对组合）。Loss 是对称 InfoNCE：对每行（image→text）和每列（text→image）各做一次 cross-entropy。鼓励配对的图文 embedding **相似度高**，不配对的**相似度低** → 图文对齐到共享语义空间。
>
> **(b)** 预训练在海量图文对上学到了**通用的语义对齐**：图像的视觉特征和文本的语义含义映射到同一空间中的近邻位置。新类别只要能被自然语言描述，其文本 embedding 就会落在语义空间中与对应视觉特征相近的位置 → 不需要在目标类上训练，cosine 相似度直接可用。
>
> **(c)** $\tau$ **太小** → softmax 极尖锐（近似 argmax），对最相似的负样本过度敏感，梯度集中在极少数样本上 → 训练不稳定、对噪声敏感。$\tau$ **太大** → softmax 接近均匀分布，正负样本区分度低 → 学不到有效对齐。**学习 $\tau$** 让模型自适应调节区分度——不同训练阶段、不同数据分布下自动找到合适的尖锐程度，比手动调更鲁棒。

### Q8 — Data Augmentation 与 SSL 的联系（novel-context 压轴 · 论述）

> *研究扩展型 novel-context 题：Data Augmentation 与自监督学习的深层联系不是讲义专章，背景已给；要求用你学过的 **Data Augmentation / SimCLR / BYOL / invariance vs equivariance** 等核心知识推理作答。*

**背景：** In supervised learning, data augmentation (random crop, flip, color jitter) is typically seen as a regularization trick to reduce overfitting. However, in self-supervised contrastive learning frameworks like SimCLR, the **choice of augmentation is the single most critical design decision** — it effectively defines what "semantic similarity" means. Two augmented views of the same image are treated as positives, and the model is trained to be **invariant** to the augmentation while remaining **discriminative** across different images.

- **(a)** In supervised learning, augmentation mainly helps with generalization. Explain why in SimCLR-style contrastive learning, augmentation plays a fundamentally more important role — what does it implicitly define? **(4 Marks)**
- **(b)** If you use overly aggressive augmentation (e.g., extreme crops that remove the main object), what goes wrong with the learned representations? If augmentation is too weak (e.g., only horizontal flip), what limitation do you get? **(5 Marks)**
- **(c)** CNNs have built-in translation equivariance from weight sharing. Contrastive learning trains for augmentation **invariance**. Explain the difference between equivariance and invariance, and why contrastive learning wants invariance rather than equivariance to augmentations. **(5 Marks)**

> [!success]- Answer
>
> **📌 考 novel-context（Data Augmentation ↔ SSL / 不变性）。** ✅「第一组」Data Augmentation +「第四组」SimCLR/BYOL +「第二组」CNN equivariance。
>
> **大白话：** 监督学习里 augmentation 只是"多看几个变体别过拟合"。对比学习里 augmentation **定义了什么是"同一个东西"**——两个 view 来自同图 = 正样本，模型被迫对这些变换不变。选错 augmentation 等于告诉模型错误的"语义等价"定义。
>
> **得分点：**
>
> **(a)** 在监督学习中，label 定义语义，augmentation 只是正则手段。在 SimCLR 中**没有 label**，augmentation 隐式定义了**什么变换下两个 view 算"语义相同"**——即定义了正样本对。选择哪些 augmentation = 决定模型对哪些变换不变 = **决定了学到的语义概念**。
>
> **(b)** **过强**（如极端裁剪去掉主体）→ 两个 view 实际内容不同却被当正样本 → 模型被迫把不同语义映射到一起 → 学到的表示**丢失细粒度语义**、质量差。**过弱**（如只翻转）→ 正样本对之间差异太小 → 模型不需要学深层语义也能区分 → 表示**不够鲁棒**、对未见变换泛化差。
>
> **(c)** **Equivariance**：输入变换后，输出做对应变换（如 CNN 平移输入 → 特征图也平移，保留位置信息）。**Invariance**：输入变换后，输出不变（如 augmentation 后表示相同）。对比学习要 **invariance**——目标是让"同一张图不同增强"的表示**完全一致**，因为分类/检索等下游任务需要的是"这是什么"而非"这在哪/什么姿态"。equivariance 保留了变换信息，反而不利于提取纯语义特征。
