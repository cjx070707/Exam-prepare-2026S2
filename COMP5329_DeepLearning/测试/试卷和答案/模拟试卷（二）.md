### Q1 — 权重初始化（场景诊断）

A 20-layer ReLU MLP barely trains: the loss hardly moves and you observe that activations in deep layers shrink toward zero as you go deeper.

- **(a)** Explain why a poor initialization can cause activations (and gradients) to shrink or explode across many layers. **(4 Marks)**
- **(b)** Which initialization scheme is appropriate for ReLU, and why does it use a different variance than the one designed for tanh/sigmoid? **(4 Marks)**
- **(c)** What goes wrong if every weight in a layer is initialized to the same constant? **(2 Marks)**

> [!success]- Answer
>
> **📌 考 W2 Weight Initialization + 梯度消失/爆炸。** ✅「第一组」Weight Init / Sigmoid。
>
> **大白话：** 初始化方差不对，信号每过一层就被放大或缩小，多层连乘后爆炸或消失。ReLU 会把约一半激活置零，需要更大的初始方差（He）来补偿；tanh 用 Xavier。所有权重相同会导致神经元完全对称、学不出不同特征。
>
> **得分点：**
>
> **(a)** 前向/反向每层乘一次权重矩阵；若每层增益 $\neq1$，多层**连乘**使激活/梯度指数级**放大（爆炸）或衰减（消失）**。合理初始化让逐层方差大致守恒。
>
> **(b)** ReLU 用 **He/Kaiming**（方差 $\propto 2/n_\text{in}$）；因为 ReLU 把约一半输出置零、削掉一半方差，需**更大**初始方差补偿。**Xavier**（$\propto1/n_\text{in}$ 或 $2/(n_\text{in}+n_\text{out})$）为 tanh/sigmoid 设计，保持前向方差一致。
>
> **(c)** 同一层所有权重相同 → 所有神经元收到**相同梯度、做相同更新**（对称无法打破）→ 等价于一个神经元，学不出多样特征。

- **(b)** Explain why placing Dropout right **before** BN can cause a train/test mismatch in BN's statistics. **(5 Marks)**

### Q5 — 写码：对比学习损失（coding）

You implement SimCLR-style contrastive learning. Given two batches of L2-normalizable embeddings `z1, z2` of shape `(N, d)` (view-2 of sample `i` is the positive of view-1 of sample `i`), implement the **InfoNCE / NT-Xent** loss with temperature `tau`.

- **(a)** Write `info_nce(z1, z2, tau)`. **(7 Marks)**
- **(b)** What role does `tau` play, and what happens if it is set too small? **(3 Marks)**

> [!success]- Answer
>
> **📌 考 W11 InfoNCE / NT-Xent。** ✅「第四组」对比学习 + 速查表 Week11。
>
> **大白话：** 把 2N 个 embedding 归一化求两两相似度/τ，对角线（自己）屏蔽，正样本是“另一视角的同 index”，对每行做 cross-entropy。τ 越小越聚焦 hard negatives，但太小会梯度尖锐/不稳。
>
> **得分点：**
>
> **(a)**
> ```python
> import torch
> import torch.nn.functional as F
>
> def info_nce(z1, z2, tau=0.5):
>     N = z1.shape[0]
>     z = F.normalize(torch.cat([z1, z2], dim=0), dim=1)   # (2N, d)
>     sim = z @ z.t() / tau                                # (2N, 2N)
>     sim.fill_diagonal_(float("-inf"))                    # 屏蔽自身
>     # i 的正样本：i+N（前半）/ i-N（后半）
>     targets = torch.cat([torch.arange(N) + N, torch.arange(N)]).to(z.device)
>     return F.cross_entropy(sim, targets)
> ```
>
> **(b)** $\tau$ 控制相似度分布的尖锐程度 / 对 **hard negatives** 的关注：$\tau$ 越小越聚焦最难的负样本（梯度权重更集中），但**过小**会使分布过尖、梯度不稳、对噪声负样本过敏感。

### Q7 — Diffusion vs GAN/VAE（novel-context 压轴 · 论述）

> *研究扩展型 novel-context 题（仿老师样卷 Q3）：扩散模型背景已给；要求结合课上核心的 **GAN / VAE** 知识，通过归纳推理作答。*

**背景：** A platform generates 512×512 images from noise. A **Diffusion Model** adds incremental Gaussian noise over $T$ steps until the image is pure noise, then trains a network to **reverse** the process by predicting the noise to remove at each step; it is trained to minimize the distance between predicted and actual noise. Inference starts from random noise and applies $T$ iterative denoising steps (computationally heavy).

- **(a)** The training objective resembles a reconstruction loss. Given input latent $x_t$ and timestep $t$, with predicted noise $\epsilon_\theta(x_t,t)$ and true noise $\epsilon$, write the diffusion training loss. **(3 Marks)**
- **(b)** Identify **two** key limitations of GANs or VAEs, and explain how the mechanism of diffusion models avoids or overcomes each. **(6 Marks)**
- **(c)** Diffusion inference is slow (many steps). Propose **two** techniques, inspired by GAN/VAE or general DL principles, to speed up sampling while keeping quality, and explain why each helps. **(5 Marks)**

> [!success]- Answer
>
> **📌 考 novel-context（W12 扩散 ↔ GAN/VAE）。** ✅「第四组」Week 12（DDPM / GAN / VAE / Flow Matching）。
>
> **大白话：** diffusion 学“预测每步加进去的噪声”。它绕开了 GAN 的训练不稳定/mode collapse 和 VAE 的模糊，代价是采样要很多步。提速思路：减少步数（蒸馏/少步采样器）、用 latent 空间扩散、或走更直的路径（Flow Matching）。
>
> **得分点：**
>
> **(a)** $\mathcal L=\mathbb E_{x_0,\epsilon,t}\big[\;\|\epsilon-\epsilon_\theta(x_t,t)\|^2\;\big]$，其中 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\,\epsilon$。（预测噪声的 MSE）
>
> **(b)**（任选两）
> - **GAN 训练不稳定 / 梯度消失**（分布不重叠时 JS 常数）→ diffusion 用**逐步去噪的回归目标**（稳定的 MSE，无对抗博弈），训练稳定。
> - **GAN mode collapse / 多样性差** → diffusion 显式建模整个加噪-去噪链、覆盖分布更全 → **mode coverage 好**。
> - **VAE 生成模糊**（重建 loss 均值化）→ diffusion 多步细化、逐步去噪 → **样本更清晰**。
>
> **(c)**（任选两，附理由）
> - **更少步数的采样器 / 蒸馏**（如 distillation 到少步、DDIM 式确定性采样）：减少 $T$ → 直接降迭代次数。
> - **Latent diffusion**（在低维 latent 空间扩散，类比 VAE 编码）：每步算更小张量 → 提速。
> - **更直的传输路径**（Flow Matching / Rectified Flow）：直线 ODE → 更少积分步、甚至 1 步。

### Q8 — 设计奖励信号对齐 LLM（novel-context 压轴 · 论述）

> *研究扩展型 novel-context 题：把语言生成当作 RL 问题，背景已给；要求结合课上 **RL / 策略梯度 / 监督学习** 知识推理。*

**背景：** You want a chatbot to produce more helpful answers. Humans find it hard to assign an absolute score to a response, but can reliably say "response A is better than response B". You decide to align the model with this preference feedback.

- **(a)** Why can't you simply fine-tune with standard supervised learning on a numeric "quality" label? Frame the language-generation task as an RL problem (what are state, action, reward?). **(4 Marks)**
- **(b)** Outline a pipeline that turns **pairwise preferences** into a usable reward and then optimizes the policy. Name the role of each stage. **(5 Marks)**
- **(c)** When optimizing against a learned reward, the model may "game" it (reward hacking). What mechanism prevents the policy from drifting too far, and why does it work? **(5 Marks)**

> [!success]- Answer
>
> **📌 考 novel-context（W10 RLHF）。** ✅「第四组」Week 10（RLHF / Bradley-Terry / KL）。
>
> **大白话：** 人给不出精确分数、只能给相对偏好，所以不能直接监督回归。把生成当 RL：state=prompt+已生成 token，action=下一个 token，reward=人类偏好分。流程 SFT→训奖励模型(Bradley-Terry)→PPO 优化；加 KL 惩罚防止跑偏骗奖励。
>
> **得分点：**
>
> **(a)** 人类偏好是**相对排序**、难量化为绝对标签 → 监督回归缺乏可靠目标值。RL 视角：**state** = prompt + 已生成的 tokens；**action** = 下一个 token；**reward** = 对完整回复的人类偏好分（常仅末步给出）；policy = LM 的 next-token 分布。
>
> **(b)** **SFT**（示范数据监督微调，得初始策略与参考）→ **Reward Model**（用偏好对 $(y_w,y_l)$ 以 **Bradley-Terry** $P(y_w\succ y_l)=\sigma(r(x,y_w)-r(x,y_l))$ 训练标量奖励）→ **PPO**（用 RM 奖励 + advantage 优化 policy，clip 限制步长）。
>
> **(c)** 在目标里加 **KL 惩罚** $-\beta D_\text{KL}(\pi_\theta\|\pi_\text{ref})$，把策略**锚定在 SFT 参考附近**。因为 RM 只在参考分布附近可靠，远离后容易被钻空子（reward hacking）；KL 惩罚抑制策略漂移到 RM 没见过的奇异区域 → 保持生成质量、防止刷分。
