## 考前 30 秒：答题骨架

### 情景题通用四步 `★★★`

**中文**：闭卷情景题每小问都按此顺序写，阅卷人最容易给分。

**Term**: issues / stakeholders / frameworks / impacts / recommendations

**背什么**：

1. **点名框架**（CIA / IR vs DR / Agile vs Waterfall / Lifecycle …）
2. **场景对应**（题干哪句话 → 框架哪一项）
3. **Impact**（对用户 / 员工 / 公司）
4. **Recommendation**（2 条 + 为什么能降低风险）

**Useful phrase**：*The issue maps to [framework element], which impacts [stakeholder] through [consequence]; I recommend [action] because it reduces [risk].*

## Block A — 价值与项目（5 条）

### 1. Professionalism in IT `★★★`

**中文**：Q1 类题：定义 professionalism → 举 accountability 行为 → 提组织举措。

**Term**: ethical and responsible / reliable solutions / own mistakes / client confidentiality / peer-feedback / mentoring

**背什么**：

- **定义**：以 ethical、responsible 方式运用技术专长，交付 reliable solutions，建立信任
- **行为**：按时交付并 own mistakes；诚实沟通进度；维护 client confidentiality
- **组织举措**：mandatory onboarding；peer-feedback / mentoring

**Useful phrase**：*Professionalism in IT means applying technical expertise ethically and responsibly to deliver reliable solutions that meet client needs.*

---

### 2. can we → should we `★★★`

**中文**：技术可行不等于应该做；专业判断考「后果与责任」。

**Term**: technical feasibility / professional judgement / trade-offs / consequences

**背什么**：

| 技术问题 | 专业问题 |
|----------|----------|
| Can this be built? | Should we proceed now or delay? |
| Which architecture? | What risks are we accepting? Who is affected? |

核心转变：**"Can we do this?"** → **"Should we do this under these conditions?"**

**Useful phrase**：*IT professional practice moves from "can we do this?" to "should we do this under these conditions?"*

---

### 3. IT Lifecycle 八阶段 `★★★`

**中文**：Q3 类题背全八阶段；跳过步骤 → technical debt；要 regular reviews。

**Term**: technical debt / obsolescence / undetected requirements errors

**背什么**：planning → analysis → design → development → testing → implementation → operation → retirement

- 跳过 formal steps → undetected requirements errors + **technical debt** → cost overruns / failures
- **Regular lifecycle reviews** → 识别 obsolescence，及时更新

**Useful phrase**：*Skipping phases leads to technical debt, causing cost overruns and failures.*

---

### 4. Agile vs Waterfall `★★★`

**中文**：需求会变 / 要早期反馈 → Agile；固定范围、阶段门控 → Waterfall。

**Term**: iterative delivery / linear phases / stakeholder engagement / early detection

**背什么**：

| | Agile | Waterfall |
|---|--------|-----------|
| 结构 | 短迭代、持续交付 | 线性阶段、文档门控 |
| 变化 | 易适应变更 | 后期改需求成本高 |
| 风险 | 频繁测试 + 客户评审 → 早发现 | 晚期才集成测试 |
| 利益相关者 | 持续参与 | 多在首尾参与 |

**Useful phrase**：*Agile reduces risk through frequent testing and client reviews, enabling early detection of issues.*

---

### 5. PERT / Delphi + 估算偏差 `★★★`

**中文**：Q7 类题：先写 estimation 作用，再写不准原因，最后选 PERT 或 Delphi。

**Term**: scope creep / optimism bias / three-point estimation / expert judgement

**背什么**：

- **作用**：预测 time / cost / resources → schedules & budgets 基础
- **不准原因**：unclear/changing requirements → **scope creep**；**optimism bias** / lack of historical data → underestimate
- **方法**：**PERT**（best / most likely / worst）或 **Delphi**（专家匿名共识）→ 处理不确定性

**Useful phrase**：*Three-point estimation (PERT) or the Delphi method uses expert judgement and probability to handle incomplete or evolving requirements.*

## Block B — 沟通与治理（5 条）

### 6. 7Cs 有效沟通 `★★★`

**中文**：写沟通改进建议时，用 7Cs 证明消息 professional、可执行。

**Term**: clear / concise / concrete / correct / coherent / complete / courteous

**背什么**：Clear · Concise · Concrete · Correct · Coherent · Complete · Courteous（7 个全背）

**Useful phrase**：*The 7Cs ensure messages are clear, accurate, and actionable, reducing misunderstandings and rework.*

---

### 7. SBAR 四步 `★★★`

**中文**：给高层 progress update 必用；Recommendation 要写清你需要对方做什么。

**Term**: concise / evidence-based update / escalation / recommendation

**背什么**：

| 步 | 写什么 |
|----|--------|
| **S**ituation | 现在发生了什么（短、直接） |
| **B**ackground | 背景与重要性 |
| **A**ssessment | 分析：原因 / 影响 |
| **R**ecommendation | 下一步 + 你需要对方做什么 |

**Useful phrase**：*SBAR provides concise, evidence-based updates that clarify issues and recommendations for quick decisions.*

---

### 8. Power–Interest 四象限 `★★★`

**中文**：Q6 类题：把 stakeholder 放进矩阵，写对应管理策略。

**Term**: manage closely / keep satisfied / keep informed / monitor

**背什么**：

| Power \ Interest | 高 Interest | 低 Interest |
|------------------|-------------|-------------|
| **高 Power** | **Manage closely**（密切管理） | **Keep satisfied**（保持满意） |
| **低 Power** | **Keep informed**（保持知情） | **Monitor**（最低投入监控） |

Practice 示例：IT → manage closely；Finance → keep satisfied；HR → keep informed

**Useful phrase**：*The power–interest matrix helps decide how much time and effort to invest in managing each stakeholder.*

---

### 9. COBIT EDM vs PBRM `★★★`

**中文**：治理题：Governance 定方向，Management 执行；背 EDM + PBRM 四域缩写。

**Term**: governance / management / alignment / value delivery / risk management

**背什么**：

- **Governance → EDM**：Evaluate · Direct · Monitor
- **Management → PBRM**：
  - Plan → **APO**（Align, Plan, Organise）
  - Build → **BAI**（Build, Acquire, Implement）
  - Run → **DSS**（Deliver, Service, Support）
  - Monitor → **MEA**（Monitor, Evaluate, Assess）

**Useful phrase**：*Governance sets direction (EDM), while management plans, builds, runs, and monitors (PBRM).*

---

### 10. Project vs Change + ADKAR `★★★`

**中文**：系统交付了但没人用 → change management 失败；用 ADKAR 诊断阻力卡在哪一步。

**Term**: adoption / deliver the solution / deliver adoption / resistance

**背什么**：

| | Project Management | Change Management |
|---|-------------------|------------------|
| 焦点 | scope / time / cost / quality | people adoption |
| 目标 | deliver the solution | deliver **adoption** |
| 成功 | on time / on budget | 员工是否在用、有信心、能胜任 |

**ADKAR**：Awareness → Desire → Knowledge → Ability → Reinforcement

**Useful phrase**：*True success comes when end-users adopt the new system and integrate it into daily work to deliver business value.*

## Block C — 安全与应急（6 条）

### 11. CIA Triad `★★★`

**中文**：Q8/Q10 必写：场景对应 C / I / A → impact → 技术对策。

**Term**: confidentiality / integrity / availability

**背什么**：

- **C**：未授权访问或泄露（plain text、弱哈希、XSS 偷 session）
- **I**：数据被篡改（交易记录、试卷文件、DB 被改）
- **A**：需要时不可用（高峰崩溃、勒索加密、考试期宕机）

**Useful phrase**：*At its core, information security ensures confidentiality, integrity, and availability of data.*

---

### 12. 漏洞五类（Human 重点） `★★★`

**中文**：找 vulnerability 时按五类扫；humans 常是 weakest link。

**Term**: weak passwords / phishing / unpatched systems / misconfiguration / insider threat

**背什么**：

| 类别 | 典型例子 |
|------|----------|
| **Human** | weak passwords、phishing、lack of training、insider threats |
| **Technological** | unpatched systems、misconfigurations、weak encryption |
| **Organisational** | lack of policies、poor IR planning、third-party risk |
| **Process** | excessive privileges、poor patch/change management |
| **Physical** | insecure server rooms、theft、power failure |

**Useful phrase**：*Human factors such as weak passwords and phishing remain among the most common vulnerability sources.*

---

### 13. NIST CSF 五函数 `★★★`

**中文**：写安全治理改进时，按五函数组织建议。

**Term**: risk-based approach / Identify / Protect / Detect / Respond / Recover

**背什么**：**Identify** · **Protect** · **Detect** · **Respond** · **Recover**（5 个全背）

**Useful phrase**：*NIST CSF provides a risk-based approach using five functions: Identify, Protect, Detect, Respond, and Recover.*

---

### 14. IRP 生命周期 `★★★`

**中文**：IR 题按阶段写：现在在哪个阶段、缺什么、下一步做什么。

**Term**: containment / eradication / lessons learned

**背什么**：Preparation → Identification → Containment（short / long-term）→ Eradication → Recovery → Lessons learned

**Useful phrase**：*Incident response focuses on detecting, containing, and mitigating incidents to minimise damage and restore operations quickly.*

---

### 15. IR vs DR vs BCP `★★★`

**中文**：正在发生攻击 → IR；系统已被破坏要恢复 → DR；业务不能停 → BCP。

**Term**: containment / RTO / RPO / business continuity

**背什么**：

| 计划 | 何时用 | 核心动作 |
|------|--------|----------|
| **IRP** | 安全事件进行中 | detect → contain → eradicate → recover |
| **DRP** | 重大中断后 | 恢复 IT 系统与服务（RTO / RPO） |
| **BCP** | 业务不能停 | 维持关键业务流程 |

**Useful phrase**：*IRP limits damage, DRP restores systems, and BCP keeps critical business functions running.*

---

### 16. Data lifecycle 控制点 `★★★`

**中文**：数据安全题：把控制放到每一环，别只写 encryption 一个词。

**Term**: minimisation / encryption at rest / audit logs / retention / secure disposal

**背什么**：

| 阶段 | 安全控制 |
|------|----------|
| collection | minimisation；input validation；informed consent |
| storage | encryption at rest；access control；backups |
| processing | RBAC；audit logs |
| sharing | TLS/VPN；masking/anonymization |
| archival | retention schedules；retrieval controls |
| destruction | wiping；cryptographic erasure |

**Useful phrase**：*Security controls must be applied at every stage of the data lifecycle.*

## Block D — 质量与伦理（5 条）

### 17. QA vs QC vs Testing `★★★`

**中文**：质量题先分清 proactive vs reactive，再写 testing 是 QC 子集。

**Term**: prevent defects / detect defects / verification / validation

**背什么**：

| 概念 | 定位 | 关键词 |
|------|------|--------|
| **QA** | proactive, process-oriented | prevent defects；standards & processes |
| **QC** | reactive, product-oriented | detect defects；verify output |
| **Testing** | QC 子集 | verification + validation；find defects |

**Useful phrase**：*QA prevents defects by improving processes; QC detects defects in deliverables; testing is a subset of QC.*

---

### 18. PDCA 四环 `★★★`

**中文**：写持续改进建议时用 PDCA 闭环。

**Term**: Plan / Do / Check / Act / continuous improvement

**背什么**：**Plan** → **Do** → **Check** → **Act**（循环）

**Useful phrase**：*The PDCA cycle supports continuous improvement through planning, doing, checking, and acting on results.*

---

### 19. Laws vs Ethics `★★★`

**中文**：伦理题：合规不够，还要讲 professional values；laws 是底线，ethics 是理想。

**Term**: minimum acceptable standard / aspirational / enforceable / conscience

**背什么**：

| | Laws | Ethics |
|---|------|--------|
| 标准 | minimum acceptable | ideal / aspirational |
| 性质 | formal, enforceable | dynamic, contextual |
| 依据 | legal system | conscience + professional values |

**Useful phrase**：*Legal compliance alone is not enough; laws set minimum standards while ethics guide responsible professional judgement.*

---

### 20. ACS Code of Ethics 六项价值 `★★★`

**中文**：伦理题先列 ACS 价值，再选 1–2 条对应场景。

**Term**: primacy of the public interest / enhance quality of life / honesty / competence

**背什么**：Public interest · Quality of life · Honesty · Competence · Professional development · Professionalism

**Useful phrase**：*IT professionals must place the primacy of the public interest above personal and sectional interests.*

---

### 21. Ethical decision models 一行对照 `★★★`

**中文**：选模型时写清：按结果 / 按规则 / 按品格。

**Term**: consequentialism / utilitarianism / deontological / virtue ethics

**背什么**：

| 模型 | 判断依据 | 局限 |
|------|----------|------|
| **Utilitarian（后果论）** | 最大化 overall good | 难预测；ends justify means 风险 |
| **Deontological（义务论）** | duties / rules；intent 重要 | rigid；duties 可能冲突 |
| **Virtue ethics（美德论）** | character / integrity | less prescriptive |

**Useful phrase**：*Consequentialism judges actions by outcomes; deontology focuses on duties and rules; virtue ethics focuses on professional character and integrity.*

## Block E — 万能答题句（Q8–Q11）

> 安全 / 应急情景题直接套用的 impact 与 recommendation 句。

### Impact 句（后果三连）

**Useful phrase**：

- *Customers face financial losses, account compromise, and loss of trust.*
- *Employees bear increased investigation, remediation, and complaint-handling workload.*
- *The company risks reputational damage, regulatory penalties, and loss of competitive advantage.*

### Recommendation 句（技术对策）

**Useful phrase**：

- *Implement secure password hashing (bcrypt/PBKDF2/Argon2 with unique salts) so credentials remain protected even if the database is compromised.*
- *Use input validation, output sanitization, and parameterized queries to reduce injection and cross-site scripting risks.*
- *Establish a formal incident response plan with defined roles, escalation paths, containment steps, and regular exercises.*
- *Maintain secure, isolated backups (offline/immutable, regularly tested) to improve recovery reliability and reduce downtime.*

### IR 场景判断句

**Useful phrase**：

- *This requires incident response to detect, contain, and investigate the active security event before damage spreads.*
- *This requires disaster recovery to restore encrypted systems and critical services within acceptable RTO/RPO targets.*
